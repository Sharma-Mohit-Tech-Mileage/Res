How Scores Are Calculated

Each category score is calculated by evaluating compliance across all applicable WCAG 2.1 success criteria and React Native accessibility best practices:

  • Screen Reader Support (95%): Evaluated across 100+ components for proper accessibilityLabel, accessibilityRole, accessibilityHint, and announceForAccessibility implementation. Score = (Components with full SR support / Total components) × 100
  • Semantic Markup (92%): Assessment of proper heading hierarchy (accessibilityRole="header"), landmark roles, and structural semantics across all screens
  • Interactive Elements (90%): Verification that all buttons, links, inputs, toggles, and dropdowns have correct roles, labels, states, and action hints
  • Visual Accessibility (88%): Color contrast ratios (4.5:1 for text, 3:1 for UI components), text scaling support, and color-independent information conveyance
  • Focus Management (94%): Proper focus order, focus visibility, programmatic focus control after navigation/actions, and useAccessibilityFocus hook implementation

4.4 Custom Accessibility Hook

useAccessibilityFocus Hook

Custom React hook for programmatic focus management:

// From useAccessibilityFocus.js /** * Returns a ref object and a function to trigger focus on the element * carrying the ref for screen readers (VoiceOver/TalkBack). */ export default function useAccessibilityFocus() { const ref = useRef(null); const setFocus = useCallback(() => { setTimeout(() => { if (ref.current) { const reactTag = findNodeHandle(ref.current); if (reactTag) { AccessibilityInfo.setAccessibilityFocus(reactTag); } } }, 100); }, [ref]); return [ref, setFocus]; }

Usage: Error messages, success notifications, form validation feedback
