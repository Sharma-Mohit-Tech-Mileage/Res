## Phase 3 — Consolidate device logic into `utils/deviceInfo.js`
`utils/deviceInfo.js` already wraps `react-native-device-info`. Extend + route through it:
- **Direct `DeviceInfo.*` calls** in `NewBillerHome`, `utility/LoginLogger`, `utility/constant.jsx`,
  `firebase/FirebaseUtils`, `manager/AnnouncementPersistence`, `network/apis/account/profile.service.js`
  → call the `deviceInfo.js` wrappers (add any missing getters).
- **`Platform.OS` helpers** (37 files): add `isIOS` / `isAndroid` to `deviceInfo.js`; adopt in the
  hottest files (don't force all 37).
- **Sizing APIs** (`Dimensions` ×11, `useWindowDimensions` ×1, `react-native-responsive-screen` ×14)
  → these are the *screen-size* concern; they move behind the new responsive utility (Phase 4), so
  components stop reading raw dimensions.

## Phase 4 — One responsive sizing utility (small + big device)
New `src/utils/responsive.js` — the single home for size logic, consumed via a hook:
- `useResponsive()` → `{ width, height, isTablet, isLandscape, deviceSize ('small'|'medium'|'large'|'tablet'), breakpoint (phone/sw600/sw720/sw840), columns(map), gutterStyle }`.
- Driven by `useWindowDimensions` (reacts to rotation).
- **Phones unchanged:** `isTablet=false` short-circuits all tablet behavior; small-device sizing keeps
  current behavior but is now centralized so the *existing* small-device quirks can be fixed in one place.
- Replaces scattered `Dimensions`/`wp`/`hp`/`getDeviceSize` (today only in `walkthroughHelpers.js`).

## Phase 5 — Apply tablet adjustments, screen by screen (on the cleaned base)
With dead/dupe styles gone and sizing centralized, each screen's tablet adaptation becomes a thin,
consistent change (consistent gutter, content max-width, multi-column where it fills well, bounded
forms/inputs/buttons, modals capped + centered). Reuse the shared styles from Phase 2 so component
files stay small.

## Execution order
1. Phase 1 + 2 **together, one component at a time** (remove unused → swap dupes for shared) — keeps each
   diff small and reviewable; phones unaffected.
2. Phase 3 device consolidation.
3. Phase 4 responsive utility.
4. Phase 5 tablet rollout (portrait first, then landscape).
