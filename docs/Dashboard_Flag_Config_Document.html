Sparklight Dashboard Configuration

Detailed image behavior for requested flag values.

Module
Dashboard
Environment Scope
All Users + Pending Activation
Document Type
Flag Behavior + Image Mapping

Configuration Payload

{
  "dashboard": {
    "pending_activation": {
      "show_sparklight_mobile_section": true
    },
    "all_users": {
      "show_new_dashboard": false
    }
  }
}

Requested Values

Flag Value Scope Primary Component
dashboard.pending_activation.show_sparklight_mobile_section true Pending activation path MobilePromo
dashboard.all_users.show_new_dashboard false All users welcome section WelcomeCard

Exactly Which Image Is Shown

With show_new_dashboard = false, the WelcomeCard uses the legacy welcome banner image.
  • Shown image: welcome-banner-home.png
  • Component path: WelcomeCard -> renderWelcomeBanner()
  • Offer banner image offer-banner-home.jpg is not used in WelcomeCard for this flag value.
With show_sparklight_mobile_section = true, MobilePromo uses the offer banner image when MobilePromo is rendered.
  • Shown image: offer-banner-home.jpg
  • Component path: MobilePromo -> renderOfferBanner()
  • Fallback image man-on-mobile-phone-app.jpg is not used while this flag is true.
  • MobilePromo appears in pending activation flow when user is mobile-eligible and not yet on mobile.
With show_sparklight_mobile_section = false, MobilePromo switches to the legacy promo image and feature-card layout.
  • Shown image: man-on-mobile-phone-app.jpg
  • Component path: MobilePromo -> ImageBackground with PromoImage
  • Offer banner image offer-banner-home.jpg is not used while this flag is false.

Visual Preview

Execution Notes

  • The two flags are evaluated in different components and can both be active in the same app session depending on user path.
  • show_new_dashboard controls image selection in WelcomeCard (all users area).
  • show_sparklight_mobile_section controls image selection inside MobilePromo (pending activation flow).

Phase 2 Behavior

In the Phase 2 rollout, all marketing banner creatives are completely hidden.
  • Hidden image: man-on-mobile-phone-app.jpg
  • Hidden image: offer-banner-home.jpg
  • Expected behavior: users should not see any marketing banner images in Phase 2.
