Validation Lists

Password requirements

  • It must be different than your username.
  • It must contain 8 to 20 characters.
  • It must include an upper and lower case letter and a number.
  • It must include at least one special character such as %, &, _, ?, #, =, -
  • Your new password cannot have any spaces.

Username requirements

  • It must contain 8 to 20 characters.
  • It must contain only letters (a-z) and numbers (0-9).
  • It must not contain any special characters (%, &, _, ?, #, =, -)
  • Your new username cannot have any spaces.

Reference & Review Notes

/Sparklight®

How to Read This Guide

This app edition follows the attached document’s section-led format: colors, typography, lists, buttons, fields, helpers, navigation and cards. Website-specific display sizes, hover/visited states and pricing cards have been replaced with app-focused examples.

HTML component specimens are recreations grounded in the local source. Embedded app excerpts come from the repository’s existing screenshots and may predate current styling. The open-dropdown image is a browser-rendered recreation, not a captured native screen.

Fields Hint example, feedback text area, actual dropdown chevron and open-state specimen, selected checkbox.
Controls / helpers On/Off toggle and status icons, realistic icon banners, surcharge disclosure and tooltip.
Navigation / cards Top header, all five bottom labels, repository screenshots and card specimens.

Implementation Differences Worth Preserving

Pressed: supported, with different feedback by component. Focused: no common custom visual style verified. Links: no visited color. Lists: dashboard feature rows explicitly expose a list role. Checkbox: purple native selection, platform-specific appearance.

Button sizing: content-driven sizing and local overrides; no invented small/medium/large scale. Surcharge: inline disclosure in the reviewed payment flow; a separate due-date tooltip is implemented elsewhere.
